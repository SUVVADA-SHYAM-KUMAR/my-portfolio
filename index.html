EV-ADAS Dashboard Using STM32

Controller: STM32F103C8T6 Blue Pill
01 — Problem

Develop a compact vehicle safety monitoring dashboard capable of sensing nearby obstacles and relaying distance information for automotive awareness.

02 — Approach

The system used ultrasonic sensing and timer-based measurements to estimate distance continuously and present the values through a communication interface.

03 — Hardware

STM32F103C8T6, HC-SR04 ultrasonic sensors, timer hardware, UART communication, and PC monitoring tools.

04 — Software

STM32CubeIDE, PicSimLab, Tera Term, VSPE, Python, and Matplotlib for data monitoring.

05 — My Contribution

Interfaced ultrasonic sensors, configured TIM2-based distance measurement, handled UART communication, supported EV/ADAS monitoring logic, and validated fault handling with a virtual terminal workflow.

06 — Result

The project demonstrated real-time distance monitoring and communication using STM32 in a simulation-focused embedded environment.

07 — Future Improvements

Expand the system with more sensor inputs, a richer dashboard display, and more advanced automotive alert logic.
